# DLH NEXUS

The most advanced AI model, powered by triple-fusion neural architecture.

## Features

- **DLH NEXUS MODEL** - Triple-fusion neural engine combining three frontier AI models
- **DLH NEXUS BOT** - Ultra-modern chat interface with streaming responses
- **Image Generation** - Create images from text descriptions
- **Vision Analysis** - Upload images and ask questions about them
- **Voice & Speech** - Text-to-speech and speech-to-text
- **Connectors** - 12+ tools including web search, weather, calculator, translator, QR generator, and more
- **Device Control** - Camera, microphone, geolocation, battery, vibration, screen capture, clipboard, notifications
- **Responsive Design** - Auto-fits phones, desktop, and tablet screens
- **Black & White Theme** - SpaceX-inspired minimal design

## Deployment

This is a static web application. Deploy to Vercel:

1. Push this repository to GitHub
2. Import the repo in Vercel
3. No build step required - Vercel will serve the static files

## Tech Stack

- Vanilla HTML/CSS/JavaScript (no framework dependencies)
- Puter.js for AI model access (loaded via CDN)
- Marked.js for markdown rendering
- DOMPurify for HTML sanitization
- Highlight.js for code syntax highlighting
